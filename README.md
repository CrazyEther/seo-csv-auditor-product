# SEO CSV Auditor — локальный аудит SEO-метаданных CSV

Оригинальная утилита для SEO-специалистов и агентств. Проверяет CSV-выгрузку локально без передачи клиентских данных стороннему сервису.

**Что проверяет:** пустые и повторяющиеся URL, Title, Description; пустые H1; рекомендованные диапазоны длины метатегов. Это не онлайн-сканирование сайта и не гарантия роста позиций.

**Формат:** CSV с колонками URL, Title, Description, H1; разделители ; , TAB; UTF-8 и CP1251. На выходе HTML-отчёт, issues.csv, summary.json. Python 3.10+, без внешних библиотек. В рабочей версии пройдено 9 unit-тестов.
